# Code of conduct

GodotUO is a fan project built by people who love Ultima Online. Keep it a place
where anyone can report a bug, ask a question or send a change without being
made to feel unwelcome.

## What we expect

- Be kind and assume good intent. Critique the code or the idea, never the
  person.
- Be patient with newcomers; everyone started somewhere, often in Britannia.
- Keep discussion on the project. Shard politics and in-game grudges belong
  elsewhere.
- Respect the rules this repository runs on: no game data, no one else's
  credentials or private details, and nothing that helps cheat on a shard you
  don't run.

## What isn't acceptable

Harassment, insults, slurs, sexual content, threats, doxxing (posting someone's
private information), and deliberately disrupting discussion.

## Reporting

Report conduct problems privately to the maintainers through GitHub's private
reporting for this repository, or to the maintainer's GitHub account. Reports
are read by the maintainers only and handled in confidence. Maintainers may
remove comments, lock threads, or block people who break this code.

This code applies in the repository, its issues and discussions, and project
spaces on Discord.
