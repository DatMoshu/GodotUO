# Screensavers: CC0 1.0

Every file in this folder (`*.ogv`, `*.png`, `screensavers.json`) is original
procedural art. `tools/bg_videos/run.py --set screensavers` generated each
one from noise functions, particles and colour ramps. They contain no Ultima
Online client art, no third-party footage and no third-party images.

They are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
You may copy, modify and redistribute them for any purpose without asking.

To regenerate them from the same seeds:

```
python tools\bg_videos\run.py --set screensavers
```
