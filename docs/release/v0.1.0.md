GodotUO 0.1.0 is the first preview of Classic Ultima Online on Godot 4 .NET: ClassicUO's network
stack, file readers and game logic carried across, with the renderer, input and audio rebuilt on
Godot. It is pre-release software. Play it on a shard you run or trust, and expect differences from
ClassicUO.

**You need your own Ultima Online installation.** Nothing in this release contains game data. The
client reads your install in place and never writes to it.

## Downloads

| File | For | Notes |
|---|---|---|
| `GUO-windows-x86_64.zip` | Windows 10/11, x64 | Unzip and run `GUO.exe`. |
| `GUO-steamdeck-linux-x86_64.zip` | Steam Deck (SteamOS), Linux x86_64 | See the Steam Deck page in the wiki. |
| `GUO-android-arm64-debug.zip` | Android arm64 | A debug build. It connects to `127.0.0.1:2593`, so reach a shard through `adb reverse` or export your own build with your shard address. |

Point the client at your install with `UO_CLIENT_DATA` (see Getting Started in the wiki). It connects to
`127.0.0.1:2593` unless you set `UO_SHARD_HOST` and `UO_SHARD_PORT`.

## What's in it

- **Windows, Android, Steam Deck** from one repository and one set of settings. Dual-screen Android
  handhelds (such as the AYN Thor) put paperdoll, status, journal and backpack on the lower screen.
- **Touch play**: centred login screens, a soft keyboard, a touch bar with Self and Cancel while
  targeting, a combat macro row, grid containers and corpses, and a screen saver for OLED screens.
- **A canvas background** behind the game: grey, wood, your own image or video, or one of ten built-in
  loops.
- **The GodotUO Asset Store**: a local catalogue you can run yourself, and a Store in Options that
  installs, updates and removes backgrounds with every file hash-checked.
- **The GodotUO editor** inside Godot: browse the UO data, view and edit the world, import your own art
  and gumps, and export the result to a ModernUO shard, or live-edit a private one.

## Known issues

See `docs/wiki/Known-Issues.md`. The main ones: the lower screen of a dual-screen handheld is crowded
at the default size, the desktop login window is the classic 640x480, and there is no web build yet
(the engine can't export C# to the web).
