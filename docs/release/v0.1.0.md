GodotUO 0.1.0 is the first preview of Classic Ultima Online on Godot 4 .NET: ClassicUO's network
stack, file readers and game logic carried across, with the renderer, input and audio rebuilt on
Godot. It is pre-release software. Play it on a shard you run or trust, and expect differences from
ClassicUO.

**You need your own Ultima Online installation.** Nothing in this release contains game data. The
client reads your install in place and never writes to it.

## Downloads

| File | For | Notes |
|---|---|---|
| `GUO-windows-x86_64.zip` | Windows 10/11, x64 | Unzip and run `GUO.exe`. |
| `GUO-steamdeck-linux-x86_64.zip` | Steam Deck (SteamOS), Linux x86_64 | See the Steam Deck page in the wiki. |
| `GUO-android-arm64-debug.zip` | Android arm64 | A debug build. It connects to `127.0.0.1:2593`, so reach a shard through `adb reverse` or export your own build with your shard address. Every build shares one signing key, so a new one installs over the last. |

Point the client at your install with `UO_CLIENT_DATA` (see Getting Started in the wiki). It connects to
`127.0.0.1:2593` unless you set `UO_SHARD_HOST` and `UO_SHARD_PORT`.

## What's in it

- **Windows, Android, Steam Deck** from one repository and one set of settings. Dual-screen Android
  handhelds (such as the AYN Thor) put paperdoll, status, journal and backpack on the lower screen.
- **Touch play**: centred login screens, a soft keyboard, a touch bar with Self and Cancel while
  targeting, a combat macro row, grid containers and corpses, and a screen saver for OLED screens.
- **A canvas background** behind the game: grey, wood, your own image or video, or one of ten built-in
  loops.
- **A gamepad on every platform**, the Windows desktop included; GUO follows whichever of pad, mouse
  or touch you used last.
- **The GodotUO Asset Store**: a local catalogue you can run yourself, and a Store in Options that
  installs, updates and removes packs with every file hash-checked: backgrounds, themes, sounds,
  presets and an optional pack of 32 screen effects.
- **Options, off until you turn them on**: Enhanced HD draws world tiles from an installed HD art pack,
  and regional audio plays a region's own music and sounds and recorded NPC voices from installed
  packs. With them off, the game is as before.
- **The GodotUO editor** inside Godot: browse the UO data, view and edit the world, import your own art
  and gumps, and export the result to a ModernUO shard, or live-edit a private one. Its Admin tab runs
  a server on your own computer: health, accounts, settings, backups, commands and a live map of who is
  where.

## Known issues

See the Known Issues page in the wiki. The main ones: frame rate zoomed far out is well behind
ClassicUO, the lower screen of a dual-screen handheld is crowded at the default size, the desktop
login window is the classic 640x480, and NPC speech is silent unless a recorded voice pack covers it.
A web build plays in Chrome on a local shard, but it needs a community build of the engine, so it is
not part of this release.
